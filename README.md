## Charlie Webb's Website

Includes a hand written index.html, some CSS, and hand drawn PNGs.

That is it nerds. If it aint broke dont fix it.

Deployed via firebase to [charlie-webb.com](https://charlie-webb.com)

### Project layout

```
public/
  index.html     HTML page
  css/           CSS files
  static/        static assets
  favicon.png
```

Firebase serves everything in `public/` as is.

Deploy: `firebase deploy`
